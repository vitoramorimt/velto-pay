# Contribuição

## Fluxo

1. Criar branch.
2. Ler documentação do domínio.
3. Implementar mudança pequena e coesa.
4. Rodar validações.
5. Criar commit descritivo.

## Commits

Use mensagens no padrão:

- `feat: ...`
- `fix: ...`
- `chore: ...`
- `docs: ...`
- `refactor: ...`

## Restrições

- Não fazer push sem autorização.
- Não fazer merge na main sem autorização.
- Não alterar regra de negócio sem validar arquitetura.
